
# E-Commerce Store

A modern, responsive e-commerce storefront built with HTML, Tailwind CSS, and Vanilla JavaScript. This project focuses on presenting products in a clean, organized, and visually appealing shopping interface.

## Overview

E-Commerce Store is a frontend web development project featuring a promotional hero section and a product catalog displayed in a responsive grid layout. The design uses colorful product cards, product information, and pricing to create a simple online shopping experience.

This project is part of my journey to strengthen my frontend development skills and build practical projects for my web development portfolio.

## Features

- **Product Listing:** Displays products in an organized grid layout.
- **Responsive Design:** Designed to adapt to different screen sizes.
- **Promotional Hero Section:** Highlights the store's promotional message.
- **Product Cards:** Presents product images or icons, names, and prices in a structured layout.
- **Clean UI:** Uses a modern layout with colorful cards and consistent spacing.

## Technologies Used

- **HTML5** — Website structure and semantic markup.
- **Tailwind CSS** — Styling, layout, and responsive design.
- **Vanilla JavaScript** — JavaScript without additional frameworks.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- The Live Server extension for VS Code (recommended).

### Installation

1. Download or clone this repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Locate `index.html`.
4. Open `index.html` using Live Server, or open the file directly in your browser.

**Note:** If Tailwind CSS is loaded through a CDN, an internet connection is required for its styles to load.
